# Contributing

Thank you for helping to make Flexible COBOL better. This repository is the
public issue tracker and the documentation of the plugin. The plugin itself is
proprietary (see [LICENSE](LICENSE)), so its source code is not here.

## Report a bug or ask for a feature

Open an issue and include:

- the plugin version (Settings > Plugins) and the IDE version
- the dialect (IBM Enterprise COBOL or GnuCOBOL) and, for GnuCOBOL, the output of `cobc --version`
- the smallest program or copybook that shows the problem
- what you expected and what happened (logs and screenshots help)

**Do not post confidential code.** Issues are public. Reduce the problem to a
small example, and remove company names, real data, connection details and
credentials before you post. For anything you cannot share in public, write to
info@ilscipio.com.

## What your contribution is licensed under

- **Issues and comments** (text, example code, logs, screenshots): you keep
  your rights. By posting, you allow ilscipio GmbH to use the content to
  reproduce, analyze and fix the problem and to improve the plugin, with no
  obligation to you. Post only content that you have the right to share.
- **Fixes and features** that come out of an issue ship in the plugin under its
  EULA (see [LICENSE](LICENSE)).
- **Documentation pull requests** (README.md, docs/) are licensed under
  CC BY 4.0, the same license as the documentation (see [LICENSE.DOC](LICENSE.DOC)).
